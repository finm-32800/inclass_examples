FINM 32900 — GitHub Actions Examples

This site is rebuilt every day at 10:00 UTC by a scheduled GitHub Actions workflow that pulls fresh data, regenerates every page, and force-pushes the result to the gh-pages branch — which always contains exactly one commit.

  • FRED GDP Chartbook — a pydoit + chartbook pipeline pulling GDP from FRED (no API key needed)
  • Treasury Futures Latest Prices — a minimal Databento pull whose API key lives in a GitHub Actions secret
